# 参数、坐标及长度

单位为mm、角度为度。`parameters.json` 是重建入口，`build.py scad` 将其完整写入 `parameters.scad`。后者已交付，可直接由OpenSCAD读取；下次重建会覆盖手改的 `parameters.scad`。

## 参数关系

| 名称 | 初值 | 含义 / 调整约束 |
|---|---:|---|
| clip_length | 29.0 | 外形包络长度 |
| clip_width | 8.0 | 外形包络宽度，须等于 `2*R_C+d` |
| wire_diameter | 1.0 | 实测线径d；改变后重算接触面、半径、销与高度 |
| bend_radius_A | 1.75 | **中心线**半径；芯轴直径为 `2*R_A-d` |
| bend_radius_B | 2.50 | 中心线半径 |
| bend_radius_C | 3.50 | 中心线半径，控制总宽 |
| inner_gap | 0.50 | 左侧内外线表面净隙，须等于 `2*R_B-2*R_A-d` |
| inner_arc_y | 19.0 | A中心Y；使A顶部避开完整C销，不能任意增大 |
| free_end_y | 7.0 | 两个自由端的中心线Y |
| springback_compensation | 0.0 | **尚未实测**的材料角度补偿；不修改目标参考轮廓；验证器检查其是否越过几何上限 |
| pin_clearance | 0.20 | 孔与金属芯轴的**直径差**；不是单边间隙 |
| pusher_diameter | 3.0 | 金属压弯销直径 |
| pusher_clearance | 0.10 | 芯轴—线材—压弯销的径向额外空隙 |
| base_width/depth/thickness | 95/75/10 | 底座外形；厚度变化要检查贯通衬套、螺钉和高度栈 |
| axis_x / axis_y | 31 / 41 | 底座工作轴位置 |
| collar_height | 8 | 限位环及上方垫圈的总高度 |
| collar_bottom_clearance | 1.5 | 限位环底面离底座顶面高度 |
| collar_max_diameter | 14 | 按轴心算的限位环最大外包络 |
| lever_thickness | 8 | 压弯杆厚度 |

宽度、半径、净隙不是互相独立的自由变量。举例：改变左侧净隙g并保持B半径时，同时设置 `R_A = R_B-(d+g)/2`；改变总宽W时同时设置 `R_C=(W-d)/2`。不相容的组合会触发断言，防止看似参数化而尺寸悄悄失配。调参后必须重新考虑标准金属销是否可买到、实际材料是否能弯，以及全程干涉。

回弹系数目前为一个统一初值。实物必须按A/B/C分别记录校准；未获得实测数据前，不以假定“统一5°”修改目标几何。`validate.py` 独立扫描每道0–15°额外过弯，记录首次碰撞，零值不表示材料无回弹。

## 成品中心线定义

原点位于外包络左下角，X向右、Y向上。令 `a=R_A,b=R_B,c=R_C,e=free_end_y,ya=inner_arc_y`：

`xl=d/2; xr=xl+2*b; xi=xr-2*a; yb=d/2+b; yc=L-d/2-c`。

| 点 | X | Y | 初始坐标 |
|---|---|---|---|
| P0 | xi | e | (2.00,7.00) 起点 |
| P1 | xi | ya | (2.00,19.00) A入弯 |
| P2 | xr | ya | (5.50,19.00) A出弯 |
| P3 | xr | yb | (5.50,3.00) B入弯 |
| P4 | xl | yb | (0.50,3.00) B出弯 |
| P5 | xl | yc | (0.50,25.00) C入弯 |
| P6 | xl+2c | yc | (7.50,25.00) C出弯 |
| P7 | xl+2c | e | (7.50,7.00) 终点 |

A圆心 `(xr-a,ya)=(3.75,19)`，从180°向0°走上半圆；B圆心 `(xl+b,yb)=(3,3)`，从0°向−180°走下半圆；C圆心 `(xl+c,yc)=(4,25)`，从180°向0°走上半圆。三道均为同一曲率方向的180°弯，且与四条直段相切。

|---|---|---:|
| P0–P1 | ya−e | 12.000000 |
| A | πa | 5.497787 |
| P2–P3 | ya−yb | 16.000000 |
| B | πb | 7.853982 |
| P4–P5 | yc−yb | 22.000000 |

最小非相邻表面间隙0.50 mm（左侧），右侧平行线净隙1.00 mm；初始参考轮廓没有线材自交或预压接触。材料变形可能引起椭圆化、中性层移动和半径变化，未包含于上述长度公式。

## 成品坐标与工位坐标

工位使用一个轴心O。A、C将成品图的相应圆心平移至O；B另转180°。变换为 `q=sign*(p-center_i)`，A/C的sign=+1，B为−1。底座坐标再加 `(31,41)`。因此每次入弯点都在 `O+(-R_i,0)`，入线沿+Y，夹持段在Y约−10 mm。

成形时，先成形部分固定；当前圆弧角φ从0到π，剩余直尾长度为 `当前后续材料总长 − R_i*φ`。圆弧出点是 `R_i*(cos(π−φ),sin(π−φ))`，余料方向为 `(sinφ,cosφ)`。这使每一个中间状态保持中心线长度，避免直接将最终图的销坐标当成三个实际工位。

压弯销中心距 `p = R_i+d/2+pusher_d/2+clearance`。接触空程 `β = acos((R_i+d/2+pusher_d/2)/p)`，故理想杆转角为 `φ+β`。这是无摩擦理想运动关系，实际接触、滑动和工具挠曲须重新标定。

## 高度与固定结构

底座顶Z=10；线材中心Z=10.5；限位环底Z=11.5、顶Z=19.5；杆Z=19.5…27.5；40 mm主轴贯通至板面Z=0；Ø3×25压弯销Z=10.15…35.15。夹块装配顶Z=15，沉头螺钉齐平。所有宽的限位/支承件均位于线材上方，不能在Z=10…11的线材平面放置宽垫圈。

夹块臂长随R改变，鼻端只越过受夹线中心0.65 mm；C工序与其它已成形线的最小名义净隙约0.35 mm。实际打印误差必须计入。夹块打印朝向与装配朝向相反，STL已翻转，重建图在装配时再翻回。
